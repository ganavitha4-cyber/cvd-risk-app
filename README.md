# ❤️ Community Cardiovascular Risk Prediction App

This is a Streamlit web application that predicts cardiovascular disease (CVD) risk using a machine learning model.

## 🚀 Features
- Predicts CVD risk based on patient inputs
- Uses Random Forest ML model
- User-friendly interface with Streamlit

## 🧠 Inputs
- Age
- Gender
- Height, Weight, BMI
- Blood Pressure (Systolic & Diastolic)
- Diabetes, Hypertension, CKD
- Smoking Status
- COVID History & Severity
- Vaccination Status

## 📊 Output
- Predicted Risk Score
- Risk Category (Low / Medium / High)

## 🛠️ Tech Used
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy

## ▶️ How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
